=============================== NUMBER GUESSING GAME IN C
===============================

A simple console-based Number Guessing Game written in C. The program
generates a random number between 1 and 100, and the player tries to
guess it. The program provides hints after each guess.

  -------------------------------
  FEATURES
  -------------------------------
  - Random number generation
  using rand() and srand() - User
  input handling - Hint system
  (too high / too low) - Counts
  number of attempts -
  Beginner-friendly C project

  -------------------------------

HOW THE GAME WORKS

1.  The program generates a random number between 1 and 100.
2.  The user is prompted to guess the number.
3.  After each guess:
    -   If the guess is higher, a hint is shown.
    -   If the guess is lower, a hint is shown.
4.  The game continues until the correct number is guessed.
5.  The total number of attempts is displayed.

  -------------------------------
  REQUIREMENTS
  -------------------------------
  - C Compiler (GCC
  recommended) - Standard C
  libraries: - stdio.h -
  stdlib.h - time.h

  -------------------------------

HOW TO COMPILE AND RUN

1.  Open terminal or command prompt.

2.  Navigate to the project directory.

3.  Compile the program:

    gcc guessing_game.c -o guessing_game

4.  Run the program:

    ./guessing_game

(Windows users may use guessing_game.exe)
